# roundtable — 多人圆桌发言契约

## 什么时候用

- 房间里有两个以上发言者，且目标是**得出结论**而不是各自表达
- 议题有真分歧，或还没人知道答案
- 讨论会跨多轮，前面已经有人发过言

不适用：单人问答、纯事实查询、任务分派。

## 发言格式（每轮都要，不许省略）

```
结论：<一句话，先给答案，不许先铺垫>
依据：<支撑它的事实/文件/数字；没有就写「无数据，这是推理」>
关键不确定：<这条结论最可能错在哪一点>
```

三段合计不超过 200 字。**超过说明你在写文章，不是在讨论。**

## 三条禁止

1. **禁止附和**。不许出现"我同意 X"作为主要论点。如果你要同意，必须补充 X 没有说到的部分，否则保持沉默。
2. **禁止复述**。不要把别人的话换个说法再发一遍。已经说过的不说。
3. **禁止无据断言**。"大多数团队都…""实践证明…"这类话，没有来源就写「未验证」。

## 三条义务

1. **必须点名反驳**。批判阶段要指出"谁的哪句话"错，不写"整体上有些问题"。
2. **改判要显式**。被说服就写「我改判：原来认为 A，现在认为 B，因为 ___」。**改判是加分，不是丢脸。**
3. **不确定要说出来**。宁可写"我不确定 X"，不要用自信语气盖过去。前面所有讨论里最有价值的一句话通常是"这里我没有数据"。

## 阶段识别

如果这一轮的提示里带【阶段 X/Y】前缀，按阶段做，不要越位：

| 阶段 | 你该做的 | 你不该做的 |
|---|---|---|
| 独立作答 | 只给自己的答案 | 猜别人会说什么 |
| 互相挑错 | 只挑错、只找缺证据处 | 重复自己的答案 |
| 自由交锋 | 直接回应最该被反驳的那一句 | 把整场复述一遍 |
| 表态 | 最终立场 + 置信度 | 引入全新论点 |
| 汇总 | 共识 / 分歧 / 下一步 | 客套开场白 |

## 收尾标记

只有在你**真的有把握这一轮没有新增信息**时才写 `[CONSENSUS]`，或确认双方都答不上时才写 `[DEADLOCK]`。
**第 1 轮不许写。** 抢着收敛会让多轮讨论变成一轮。
